# Скриншоты и записи для секции «Живой пример»

Положите сюда файлы и пропишите их в `apps/web/components/landing-media.ts`.
Пока запись в манифесте `null`, секция показывает встроенный макет переписки —
так на странице никогда не появится битая картинка.

## Скриншот

```ts
{ kind: "image", src: "/screenshots/shop-instagram.png", width: 1200, height: 900,
  alt: "Переписка агента с клиентом о наличии и доставке" }
```

Ширину и высоту укажите настоящие — без них вёрстка прыгает, пока файл грузится.
Формат: PNG или WebP. Грузится лениво, вне первого экрана.

## Короткая запись экрана

```ts
{ kind: "video", src: "/screenshots/booking.mp4", poster: "/screenshots/booking.jpg",
  alt: "Агент согласовывает время записи и передаёт вопрос владельцу" }
```

- MP4 (H.264) — понимают все браузеры.
- Постер обязателен: это первый кадр, который видно до загрузки и на мобильном
  интернете. Без него будет чёрный прямоугольник.
- Видео идёт без звука и без кнопок, зациклено. Звук не включайте — на телефоне
  автовоспроизведение со звуком браузеры просто заблокируют.
- Держите ролик в пределах 10–15 секунд и нескольких мегабайт: он грузится
  вместе со страницей.

## Перед публикацией

Замажьте на скриншотах телефоны, имена и адреса реальных клиентов.
